# สถานะและสิ่งที่ต้องทำต่อ

**อัปเดต V2 วันที่ 29 ตุลาคม: เครื่อง Online แล้ว ไม่ต้องเริ่มซ้ำ แต่การจำกัดโฟลเดอร์ยังไม่ผ่าน อ่าน [ขั้นตอน V2](V2_OWNER_STEPS.th.md) แทน ขั้นตอนด้านล่างเป็นประวัติ V1**

วันที่ 28 ตุลาคม 2026: **PARTIAL — ยังไม่เชื่อม ChatGPT เว็บกับไฟล์ในเครื่องสำเร็จ**

- ตรวจเครื่องและรุ่นโปรแกรมแล้ว ไม่ลง DWB หรือ Tunnel เพิ่ม
- เตรียม sandbox และสคริปต์อ่าน/เขียน/อ่านกลับ/ลบไฟล์จำลองเพื่อทดสอบในเครื่อง
- Remote Desktop Commander เดิมรายงานเครื่อง Offline จึงหยุดตรงนี้ ไม่วนลองซ้ำ
- ไม่แก้โปรเจกต์ Acash, -SEED, EIMS หรือ AgentOS และไม่เปิดสิทธิ์ให้ระบบใหม่เข้าถึง

คุณทำต่อได้ดังนี้:

1. เปิดแอป Desktop Commander เดิม และตรวจเครื่องใน [หน้าจัดการอุปกรณ์](https://mcp.desktopcommander.app/) ให้เป็น Online
2. ตรวจสิทธิ์โฟลเดอร์จริง จำกัดการทดลองไว้ที่ `sandbox` ของ repo นี้ก่อน อย่าเปิดทั้งไดรฟ์หรือโฟลเดอร์ผู้ใช้
3. ใน ChatGPT เว็บที่เปิด connector นี้ ให้ลองอ่าน `sandbox/hello.txt` ด้วย absolute path ของเครื่องจริง แล้วเก็บผลตอบกลับ
4. ทดสอบการปฏิเสธโฟลเดอร์นอกขอบเขตด้วยไฟล์จำลอง ก่อนเปิดทดสอบเขียน อย่าใช้ไฟล์ลับจริงเป็นตัวทดสอบ

หากยังต้องการ DWB ให้ส่งข้อความใน [RESEARCH_HANDOFF.md](RESEARCH_HANDOFF.md) ให้ ChatGPT Research ตรวจ source และความเข้ากันได้ก่อน ไม่มีหลักฐานว่าการเปลี่ยน Tunnel ที่ DWB จัดการเองจาก 0.0.11 เป็น 0.0.18 จะใช้ได้ทันที
